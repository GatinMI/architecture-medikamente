# Задание 1. Анализ безопасности системы

Анализ состояния As-Is компании «Медикаменте» в части работы с данными: потоки данных по бизнес-процессам, аудит мер безопасности, список проблемных зон и план защиты данных.

| `improvements.md` | Данные для защиты, механизм тегирования, меры по каждому потоку |

## Как читать диаграммы

Каждый файл - одна диаграмма на бизнес-процесс, в два листа:

- **As-Is** - как данные сейчас двигаются по системам компании. Жёлтые заметки - проблемы в конкретном месте потока;
- **To-Be** - тот же поток с рекомендованными мерами защиты. Зелёные заметки и зелёные стрелки - что нужно использовать на каждом этапе.

Обозначения:

- серый прямоугольник - внешняя сущность (человек, устройство, внешняя организация);
- эллипс - процесс, операция над данными;
- синий пунктирный прямоугольник - хранилище данных (файл, база, система);
- большой пунктирный контур - система, в которой живут хранилища;
- стрелка с подписью - поток данных, на стрелке - что именно передаётся.

Имена систем и файлов совпадают с диаграммой лендскейпа компании (FileServer, `Patients`, `Journal-Doctor-FIO`, `RegistryByDate`, 1С:Бухгалтерия, 1С:Торговля и склад, ККМ, Exchange, Laboratory).
